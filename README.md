# alvaldes/tap

Homebrew casks for [Netty](https://github.com/alvaldes/netty) and [JUMP](https://github.com/alvaldes/jump).

```sh
brew install --cask alvaldes/tap/netty
brew install --cask alvaldes/tap/jump
```

Neither app is notarized yet, so macOS blocks its first launch. Open
System Settings › Privacy & Security and choose **Open Anyway**.
